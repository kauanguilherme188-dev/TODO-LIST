# Todo List - JavaScript

## Sobre o projeto

Projeto desenvolvido com foco em praticar lógica de programação e aprofundar conhecimentos em JavaScript puro (Vanilla JS).

A aplicação permite o gerenciamento de tarefas de forma dinâmica, utilizando manipulação do DOM e armazenamento local no navegador.

---

## Funcionalidades

* Adicionar tarefas
* Atualizar tarefas
* Remover tarefas
* Marcar tarefas como concluídas
* Salvar tarefas no localStorage
* Manter dados mesmo após recarregar a página
* Exibir data e hora de criação das tarefas
* Interface responsiva

---

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

---

## Objetivo

Fortalecer fundamentos de desenvolvimento front-end, lógica de programação e manipulação dinâmica de dados com JavaScript.
